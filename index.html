FIRE CONTROL / RANGE FINDER

War Dogs Mortar & Artillery Calculator

Paste your Self and Target game coordinates. The calculator returns straight-line range in metres.

How to use

  1. Press M to open the map.
  2. Right-click and select Mark Coordinates.
  3. Press Ctrl+A to select the coordinates, then Ctrl+C to copy them.
  4. Paste the first set into Self Coordinates; repeat the marking and copy process for the target, then paste it into Target Coordinates.
  5. After entering both sets, middle-click the target on the map to aim the mortar. Use this calculator’s output as the mortar range.
Example: x83.82, y122.23
Labels may appear in either order.
